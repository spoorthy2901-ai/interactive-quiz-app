# Online Quiz App

A responsive multiple-choice quiz application built with HTML, CSS, and JavaScript.

## Features
- 10 web-development questions
- Optional player name
- Progress bar and live score
- Instant answer feedback and explanations
- Final score and percentage
- Restart quiz option
- Responsive layout for mobile and desktop
- No framework or installation required

## Project files
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — questions, quiz logic, scoring, and results

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your web browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `online-quiz-app`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under the build and deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Customize
Edit the `questions` array near the top of `script.js` to change the quiz questions, choices, correct answer index, and explanation. Answer indexes start at `0` (A), `1` (B), `2` (C), and `3` (D).
